# Calculator

A browser-based calculator built with HTML, CSS, and vanilla JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## Live Demo

[Try the Calculator](https://ashfakahamed07.github.io/calculator/)

## Features

- Addition, subtraction, multiplication, and division
- Chained calculations
- Repeated equals operations
- Decimal number support
- Floating-point result rounding
- Division-by-zero error handling
- Clear and Backspace buttons
- Responsive layout
- Keyboard-focus styling for accessibility
