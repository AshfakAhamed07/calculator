# Calculator

A browser-based calculator built with HTML, CSS, and vanilla JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## Features

- Addition, subtraction, multiplication, and division
- Chained calculations
- Repeated equals operations
- Decimal number support
- Floating-point result rounding
- Division-by-zero error handling
- Clear and Backspace buttons
- Responsive layout
- Keyboard-focus styling for accessibility

## Built With

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone this repository.
2. Open `index.html` in your browser.

## What I Learned

- Managing calculator state with JavaScript variables
- Handling click events and user input
- Working with strings, numbers, and type conversion
- Debugging calculation logic and edge cases
- Building a responsive interface with CSS Grid and Flexbox
